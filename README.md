# SHOHRA | شُهرة — وكالة تسويق رقمي

موقع البورتفوليو الرسمي لوكالة **SHOHRA | شُهرة** — وكالة تسويق رقمي ونمو متاجر إلكترونية مقرها جدة، المملكة العربية السعودية، وتخدم المملكة ودول الخليج.

The official portfolio website of **SHOHRA | شُهرة**, a digital marketing & e-commerce growth agency based in Jeddah, Saudi Arabia — serving KSA & the GCC.

---

## ✨ المميزات | Features

- 🌙 تصميم داكن فاخر بمستقبلية عالية (Dark Luxury Futurism)
- 🌍 دعم كامل للعربية (RTL) مع تبديل فوري للإنجليزية (LTR)
- ✨ خلفية جزيئات تفاعلية (Interactive Particle Background)
- 🎞️ حركات سلسة بـ Framer Motion + تأثيرات زجاجية (Glassmorphism)
- 📱 متجاوب بالكامل على جميع الشاشات
- 🖼️ معرض أعمال + عرض تفاعلي للقطات (Lightbox)

## 🛠️ التقنيات | Tech Stack

- **Next.js 16** (App Router) + TypeScript
- **Tailwind CSS**
- **Framer Motion**
- **Prisma** + SQLite
- **shadcn/ui** components

## 🚀 التشغيل محليًا | Getting Started

```bash
# 1) تثبيت الحزم
bun install
# أو: npm install

# 2) إعداد متغيرات البيئة
cp .env.example .env

# 3) تهيئة قاعدة البيانات
bunx prisma db push

# 4) تشغيل خادم التطوير
bun run dev
# أو: npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) في المتصفح.

## 📦 البناء للإنتاج | Production Build

```bash
bun run build
bun start
```
